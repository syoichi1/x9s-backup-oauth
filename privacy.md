# Privacy Policy

X9S Backup is a private personal backup utility used only by the repository owner.

The application accesses Google Drive only to store and retrieve encrypted backup data created by the owner's personal Debian server.

The application does not sell, share, or disclose user data to third parties.

No user data is used for advertising, analytics, profiling, or marketing.

Google account authorization is used only for access to the owner's Google Drive backup storage.

Backups are encrypted before being stored.

For questions about this application, contact the repository owner.
